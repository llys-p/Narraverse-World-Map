# NPC4：可兑现协商与可替换语言模型入口

## 给用户

猎人可以与玩家商量：实际修理工具，换取一段时间的借用。提出条件、接受、实际履约、领取、按时或逾期归还都产生真实状态；口头声称完成不会修好工具。允许半天/一天等期限的提议与还价，显示双方最终约定。

另接一个默认关闭、可更换服务商的语言模型接口，读取猎人自己知道的事和近期交谈，产生自然回复及动作/协商建议。项目无已配置模型或密钥，本轮不付费调用、不声称真实模型效果通过；以本机受控HTTP替身验证协议与整条消费链。原按钮及规则文字入口保留。后续选择模型、提供配置并实际评估才算自由对话体验验收。

## 给AI

- 新 `campaign-negotiation-village` / fixture4 / map4，沿用DTO5/format11；旧1/2/3重演不变，不迁移日常档。新增独立启动器及测试目录。
- 第一片协商限定修理同一猎人工具换取借用：提议→还价/给出条款→玩家明确接受→实际修理满足条件→玩家领取→归还/违约；一次仅一份未结束约定。条件、期限、记忆及物品所有者/持有人必须可回放、可重开、可审计。食品交换、抵押金、主动发起及泛化任务暂留后续。
- 有界结构化模型输出只能包含回复、有效记忆引用及支持的动作/条款建议；不能写信任、生成物品、伪造事实、直接执行建议。对话记录是“双方说过什么”，与客观事件分开。已保存回复在重演时不重新调用模型。
- 模型只读猎人自身需要/固定人物设定/可知记忆及有限近期对话，不读取其他人物私有记忆或全知账本。私有上下文和密钥留服务端，不暴露浏览器。
- 模型HTTP传输有超时、响应/输入上限及并发限制；默认关闭、无隐式付费/自动重试/旧Laya桥。端点仅由本项目进程配置，不接受玩家指定URL。使用签名绑定世界、revision、原话、回复与建议，防止前端伪造模型回执；已提交原DTO跨重开重试不要求旧进程签名密钥。
- 前端解释/模型生成不写世界，明确提交交谈后才显示已说出的回复；动作建议另由玩家确认执行。待确认保留原DTO；晚到、跨世界/人物/修订的模型草稿失效。模型失败明确显示，可继续使用已有交互。
