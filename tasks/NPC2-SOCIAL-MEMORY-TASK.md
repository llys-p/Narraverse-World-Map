# NPC2：行为、可知记忆与关系反馈

2026-10-23，用户要求在单 NPC 线上支持偷、抢、砸、交流、威胁、帮助等更丰富交互。基线 `4742c70`，分支 `codex/npc-social-memory-20261023`。

## 给用户：这一片交付什么

围绕猎人及其工具包，接通交谈（近况/往事/关系）、威胁、偷取、抢夺、砸坏、帮助修理、归还、道歉和请求帮助。工具包有唯一归属、实际持有人及耐久；互动有真实结果，NPC 可以拒绝或退避。

NPC 的反应来自自己的亲历、目击和发现，以及信任、恐惧和未化解的伤害。未目击的偷窃只产生可被后来发现的失物，不直接给失主“小偷身份”。帮助不会抹掉先前受害记忆。对话从实际可知经历中检索回应；本片使用明确意图和确定性表达，任意自由语言理解仍需后续 E1 语义评测与模型接入。

## 给 AI：实施合同

- 新入口 `campaign-social-village`，campaign fixture3 / map3；保留旧1/2世界及原入口。一个明确 `PlayerInteract` 命令、DTO5，旧fixture拒绝新增交互；无付费模型、部署或真实档迁移。
- 互动消耗1世界刻，完成时重查距离、存活和物品条件；收到同ID重试只返回原回执。观察、关系、记忆和资产在同次提交落盘。
- 工具包是新增的唯一实体，权属始终为猎人；偷/抢/借用只改变持有者，破坏/修理改变实际耐久。不借用食物或金币账本伪造物品变动。
- 猎人、村长、商人各自只保存当地目击记录；暂不传播流言。关系分维度保存，最多32条情景记忆，优先保留高影响事件；事件引用和关系不因重开或检索再次累计。
- 威胁/抢夺可以导致拒绝或避开玩家，影响村内行走；已知工具损坏/失去时优先返回歇脚处，实际缺工具或耐久不足时不能工作。玩家离开3格以上后，每24刻恐惧降低5；等待不恢复信任或消除伤害。已执行的帮助、借还及未归还承诺形成持久经历。
- 页面提供明确动作与对话主题，显示真实回应、可见工具状态和 NPC 主动提及的经历；不展示全知心理字段或未目击者的秘密记录。

## 最小验收与停止点

覆盖有/无目击偷窃及后来发现、抢夺抵抗/屈服、破坏与有效修理、信任与恐惧分离、帮助不抹除伤害、借还、避让对行动的影响；旧fixture拒绝、过期距离拒绝、完整重放与篡改拒绝、真实HTTP保存重开与幂等、页面消费者严格校验。只跑相关有界检查，保留失败证据。更新 PROJECT_CONTEXT，提交草稿PR；控制树/Projects待主线同步。停止于单 NPC 交互候选，不声称通用智能、自由对话或完整犯罪司法系统。
