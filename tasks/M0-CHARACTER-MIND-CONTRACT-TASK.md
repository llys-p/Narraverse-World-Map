## 最小产品边界

M1 只做：角色可知 DTO → 有界结构化观察/注意 → 少量 Belief 与反证 → 最小持续意图 → 既有合法命令或无外显行动 → 权威结果 → 本人记忆/判断更新 → 保存恢复。检查器必须消费这条真实链。

M1 可先仅为场景所需的一种命题实现确定性判断，不构造通用自然语言逻辑引擎。情绪/价值/人格四轴/复杂计划统一列为 M2 以后；不能为了“未来方便”新增不参与行为的空字段。三层意图的数据边界在 M0 写清，M1 只落实际参与该场景的最小状态。

## 必须冻结的合同

1. **真实消费路径**：指出 D2C fixture→NPC knowledge→规划→内部命令→日结算→service commit→恢复审计各入口与调用方。当前 `actor-knowledge.mjs` 不支持 `d-player-v2`；现有 `planSocietyDay` 接完整世界，不能只在提示词层声称信息隔离。逐条列出可复用/需适配/不可直接使用的函数。
2. **信息与判断 DTO**：观察的发生 tick 与获知 tick、渠道、说话者/对象、原事件引用、命题类型、确信与未知、证据/反证、过期与淘汰；把“发言发生”与“发言内容为真”分开。先用哪个渠道、允许哪些来源、谁能提交结构化发言，均须明确；不能允许页面伪造目击/事实。
3. **选择与执行**：列出最小候选的精确名称/参数、现有动作映射、顺序与同分规则。本人可知条件影响规划，世界真实条件决定最终通过/拒绝。无行动、观察、主动休整必须有不同语义；持续意图不得等同于未提交世界命令，不能重试时重复扣款。
4. **同 tick 与唤醒**：在 D2C 已有顺序中标明观察、判断、内部动作和结果回写的位置。定义新信息/需求/目标触发、去重、冷却、每次推进上限、死亡/离开区域处理，以及无新信息时是否计算；同 tick 因果不能循环无限重评。只改新 profile。
5. **版本与恢复**：给出 rules/config/knowledge/输入/checkpoint/service 版本矩阵和注册位置，明确哪些复用、哪些升级；列出持久状态、可重建数据、输入记录及完整历史审计路径。断点恢复后 Belief/意图/游标/钱货/回执均一致，不重新调用模型，不改变旧 C/D 轨迹。
6. **边界与预算**：冻结具体整数上限：人物数、命题/证据/反证数、字符串/输入字节、候选/计划步数、唤醒与推进输出数；超限整次拒绝或确定性淘汰、引用保留规则及错误码。不是性能承诺；性能只报告实际测量场景，不虚构毫秒指标。
7. **只读检查器**：冻结核心投影导出与 HTTP DTO、revision、错误/空态、刷新/选择人物交互；显示本人可知输入、Belief、意图/候选、命令与回执。开发者全知对照显式分区，接口不复用于玩家/NPC 上下文，不提供修改心理字段按钮。多标签页读取不能改变 tick/资产/状态文件。
8. **Provider 预留边界**：写清未来请求与接受位置、actor/context 绑定、过期/重复/死亡/超限/fallback、单写者与重演职责即可；M1 不实现空模型框架，也不发出真实推理调用。未来提出策略的 Provider 仍只返回候选，不直接写世界。

所有决定写进共同合同，三路任务书只引用公共字段并定义自身文件/验证/交付；不能各写一套不同 DTO。阶段推进依赖必须是可核对的交付物，不以“足够智能/更像人”作为门槛。

## 必须写成输入与预期结果的场景

| 编号 | 固定条件与单一变量 | 预期与需要证明的因果 |
|---|---|---|
| K1 可知隔离 | 相同世界；甲获知结构化“无药”说法，乙看到有效供给；另做同一角色两份初态只换证据的配对 | 信息不会跨人物泄漏；只变证据可改变判断/选择，不能用职业或资产差异冒充信息作用 |
| K2 未知/反证 | 同场景但未收到信息；随后通过合法渠道给予反证 | 未知保留未知，不猜全知库存；收到新证据后判断可修正、持续意图可继续；旧来源与反证仍可追溯 |
| K3 真实消费/拒绝 | 角色相信有药且计划购买；提交前另一合法命令先耗尽最后一份药 | 成功路径有真实钱货变化，竞争路径明确拒绝且无额外损失；本人只得到允许观察的结果，后续选择可改变 |
| K4 无外显行动 | 只有主观立场变化，没有合法/必要动作 | 心智状态可变化，资产/位置不凭空改变；无行动不等于主动休整、不增加额外耗时；正常日结算仍发生 |
| K5 中途保存/重放 | 在观察后、执行前或失败后保存，重启继续；相同有序输入重复/分块推进 | 完整状态/输入/回执一致；证据只应用一次，命令只扣一次，恢复不推理；旧 profile 的直接关联兼容用例通过 |
| K6 检查器与边界 | 读取两位人物、切换/刷新/双页签；伪造他人来源、坏版本、超预算、已死人物 | 真核心投影与页面一致；读取零写入；非法输入按冻结错误码拒绝，无事实/信息越权 |

M0 交付的是可据此编写测试的精确 fixture/操作表，不要求本轮跑这些测试。若既有动作无法完成示范链，应缩小命题与选择范围，或在合同显式新增一个必要输入；不能暗中做通用对话系统。
