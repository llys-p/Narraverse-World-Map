# NPC5：单猎人多轮对话评测入口

2026-10-24（Asia/Shanghai）。用户要求继续模型接入与对话验证；基准 NPC4 `1b4d9068d60a3e1ba0ff23d5fce5004e0d164a26` / PR #12。独立分支 `codex/npc-dialogue-evaluation-20261024`。

## 给用户

把讨价还价、否认、转述、撒谎和旧事回忆做成固定的多轮场景。每次测试从同一可重建世界开始，真实发生的修理/破坏/归还与说过的话分别记录。报告显示模型原话、行动建议是否合要求、记忆引用是否有来源，以及哪些判断还须人来验收。

当前本项目未配置模型或密钥。本轮先完成无需真实模型的评测设施与受控协议验证；不把受控回复或场景检查当作真实模型能力通过。真实调用须有本项目配置与明确授权范围，缺少时给出具体缺项。

## 给AI

- 不改世界规则/存档/fixture版本或日常启动器，不部署、不合main。只新增公开开发场景、CLI评测器与必要的Provider诊断；模型仍由NPC4适配器调用，建议不自动执行。
- 场景从真实fixture4及真实命令构建，不手工捏造NPC事实记忆。连续轮次保存已生成交谈，后续上下文来自同一世界。固定剧情动作独立于模型建议，明示为测试脚本的玩家选择。
- 默认离线计划：零网络/零模型调用，不输出语义通过率。真实模式显式选场景、设请求数量上限和调用开关；未配置、请求预算不足或已有输出文件时先拒绝，不边付费边发现缺项。串行、无自动重试；失败后同场景剩余轮次标为阻塞。
- 报告区分确定性检查、建议结构/引用检查、人工语义复核及未运行项。自然措辞不做精确字符串匹配；不使用关键词通过冒充理解能力。语义质量总评默认待人工复核，未复核不能整体PASS。
- 原话、建议、规则核验、上下文来源引用、请求时延/服务商报告的tokens（缺失为unknown）及源码/场景指纹可追踪；报告不保存密钥、Authorization、完整上游错误或真实存档。提供可离线打开的HTML报告，转义所有模型文本，不能执行模型返回的HTML/脚本。
- 数据是作者自写的公开开发样例，不是盲测、独立金标或旧E1准入。控制树/Projects仍待主线复核。

## 停止点

定向验证场景因果、建议约束、未目击知识边界、多轮承接、默认零调用、预算/配置/输出前置拒绝、失败阻塞、服务商usage缺失、报告转义与原Provider相邻回归。公开证据脱敏绝对临时路径并保留原始SHA；更新当前状态、使用说明、源码索引及草稿PR。没有真实配置时，到可直接运行的评测入口交付，明确请求服务/模型及调用预算，不伪造真实模型结果。
