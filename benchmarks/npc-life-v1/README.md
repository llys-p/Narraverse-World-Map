# 猎人生活状态评测

fixture5，两个作者自写的公开开发场景、八轮。工作/买粮场景使用实际时间推进至112、144、160、288刻，区分抵达、实际领工资、准备买粮与日结后的库存。赠粮场景使用真实赠粮命令，检查赠粮后暂停买粮、日结后当前余额和剩粮。场景为开发回归，不是盲测。

```sh
node scripts/evaluate-npc-dialogue.mjs --suite life-v1 --out artifacts/npc12-life-plan.json
```

默认plan零模型调用、不读取密钥。脚本指定的推进和赠粮直接经过世界审核，与模型建议无关。fixture5评测仅允许给猎人赠送一份粮食的原命令；额外数量、错误人物和旧版场景都拒绝。模型不能因此提出赠粮、工作或购物的新动作权限。

真实复测范围：本集最多8次请求，串行、无自动重试，失败阻塞当前场景后续轮；上下文只包含临时虚构世界中猎人自己的受限资料，建议不执行。明确新的调用授权/预算和本项目模型配置后，才能运行：

```sh
node scripts/evaluate-npc-dialogue.mjs --suite life-v1 --mode live --case all --allow-model-calls --max-requests 8 --out artifacts/npc12-life-live.json
```

请求次数不是金额上限。逐条检查是否把意图说成完成、是否用当前库存而非过去增量、是否编造拒绝原因或他人资产，以及是否又机械回到修理话题。格式、引用与受控接线通过不代表真实语言质量。本片外部模型0调用，真实模型效果未验。
