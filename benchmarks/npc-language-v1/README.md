# NPC3 文字入口：开发反例

这是玩家文字到现有动作的有界路由开发集，不是通用自然语言模型评测，也不是E1五个社会信号的金标。全部样例由本轮作者自写，标签依据在每行basis字段；没有独立盲审、训练/校准/盲测切分，不用这些公开例子的命中率宣称泛化能力或模型准入。

主线main/PROJECT_CONTEXT已明确旧Laya A/B筛查收档、正式准入为空；本片不修改或重开 `benchmarks/npc-socialsignal`，不调用模型、扩400样本、微调或接E2。未来Provider需要另一份有真实消费目标、独立标注和未见样本的合同。

`ready`表示整句能对应一个受支持的意图，仍需玩家点击已显示动作，之后世界可拒绝。`clarify`表示需选择一个明确意思；`unsupported`、`invalid`、`empty`都没有动作。条件威胁仅对应威胁，不实际打人、砸物或抢物。询问往事不会把问题里的自述写成客观历史。

`context=tool`模拟同世界同revision刚确认的工具交互，`talk`只模拟普通交谈，`none`无指代。生产上下文由严格验证过的真实回执产生，过期、刷新或换世界失效。输入预算240个UTF-16码元；整句保守匹配，不静默截断，不删除引号或不可见格式符来拼出动作。

复跑：`node scripts/check-npc-language.mjs`。报告包含逐例结果、家族统计、接受覆盖、错误就绪数（不是实际执行数）与固定拒绝基线，注明作者公开开发例的范围；没有confidence或E1准入结论。失败不得删除或改标签以掩盖错误。
