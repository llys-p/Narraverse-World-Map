# E1 / M1：Narraverse 中文 NPC SocialSignal 标签规范 v1

状态：**待冻结**。冻结条件 = 盲审回收、分歧裁定完成，并在 `split-manifest.json` 写入内容哈希。
冻结后本文件与 `question-templates.json` 进入只读；打开最终测试结果后不得再改定义、选项措辞或阈值。

适用范围：仅 E1 离线 benchmark。这里的标签是**该 NPC（Actor）的感知输出**，不是世界事实，也不是道德判断。任何标签都不直接写入 trust/fear 数值，数值幅度由确定性规则映射（E2 合同）。

---

## 0. 全局标注原则

### 0.1 Actor 可见性（最高优先级）

每个样本的输入由三部分构成，标注只能引用这三部分：

1. `persona`：该 NPC 的身份、与玩家的既往关系、**它自己明确知道或明确声明过的边界**、人格基线（谨慎/警觉程度）。
2. `history`：该 NPC 亲历或被告知的事件（有界、按时间排列）。玩家私下发生、NPC 未被告知的事**不得**作为依据。
3. `turn`：当前玩家的话语或行为（含当场可见的行动、表情、交付物）。

判定：**如果某个结论只有"读心"或"全知视角"才能得出，就必须给 `不确定` / `信息不足`。** 标注者不得比 NPC 知道得更多。若样本同时提供 NPC 不可见的事实，该字段必须放在 `hidden_truth` 中，仅用于生成样本，不参与任何标签判定，也不得进入模型输入。

### 0.2 单选与优先级

五个信号各自独立单选。同一信号内部出现冲突时，按以下优先级裁定，并在 `basis` 里写触发的规则号：

- 先判**是否有可见线索**，无线索 → `信息不足`/`不确定`，不要勉强归类。
- 有可见线索时，按**对 NPC 造成的可观察后果**归类，而非按玩家措辞的礼貌程度、语气外壳。
- 同一话轮同时具备两类线索（例：礼貌外壳 + 施压内容）→ 按内容归类（外壳不降级）。
- 线索互相矛盾且当场无法核实 → 按 `矛盾线索` 规则处理（见 §0.3）。

### 0.3 矛盾线索

`history` 与 `turn` 给出方向相反的可见证据时：

- 若 `turn` 是当场可核实的具体行为（交付物、动作），行为优先于口头陈述。
- 若两者都是口头且 NPC 无法当场核实 → `deception = 有欺骗线索`（不一致本身即线索），其余信号按较近、较具体的一条判，并在 `basis` 标 `contradiction`。
- 若样本意图为"证据势均力敌"（明确标注 `ambiguous_by_design`）→ 一律 `不确定`/`信息不足`。

### 0.4 必覆盖的表达维度

每个信号的最终测试集都要覆盖以下维度，缺任一项则该信号标"覆盖不足"：
否定、讽刺/反话、礼貌威胁、多人物指代（他/她/第三人称混淆风险）、矛盾线索、身份与关系差异（同一话轮对陌生人和对老主顾含义不同）、边界未告知、中英夹杂、长上下文（历史事件多到需要截断）。

### 0.5 语言与措辞

样本为中文口语书面混合，允许中英夹杂。标签选项固定为中文短词，不加解释性后缀（避免给模型提示性偏置）。选项顺序按 `canonical_order`，置换测试用 `rotated` 与 `reversed`。

## 1. `social_act` — 交互性质

**问题**：从该 NPC 的视角，玩家这次交互在做什么？
**选项（canonical）**：`威胁` / `示好` / `求助` / `合作` / `中性` / `不确定`
**只描述交互性质**，不含道德评价，不含 NPC 情绪强度。

| 类 | 定义 | 正例 | 反例（易误判） |
|---|---|---|---|
| 威胁 | 含对 NPC 的人身、财物、声誉或处境施加损害的可见线索，**无论措辞多礼貌**。 | "岑婆婆，您这药摊，我劝您收了比较好。"（当场指其摊）/ "帮我改口供，不然我就说那晚你也去了。" | 玩家自陈危险的客观处境（"山里有熊，我打不过"）→ 属 `求助`，非威胁。 |
| 示好 | 主动给予、致意、道歉、送礼、承诺好处，无对价要求、无施压线索。 | "路上摘的，给您带一把。" / "上次是我失礼，对不住。" | 给好处同时附带施压（"这点心意，您就别报官了"）→ 属 `威胁`（内容优先）。 |
| 求助 | 请求 NPC 帮忙、庇护、指路、赊账，玩家处于弱势或请求地位。 | "求您给口药，我娘烧一天了。" / "我第一次走这条道，能带我一段吗？" | 请求里带胁迫（"你要是不救她，我就……"）→ 属 `威胁`。 |
| 合作 | 双向对等交换、共同做事、分工、议价，双方各有付出与所得。 | "我护你过隘，你分我三成皮子，讲定。" / "药材我出，你出手艺，卖了对半分。" | 单向无偿给予 → `示好`；纯信息问答无涉利益 → `中性`。 |
| 中性 | 无上述性质的问询、寒暄、陈述、闲聊。 | "今日集上人多。" / "这个值几个钱？" | 冷漠但不施压的拒绝 → `中性`；若拒绝伴随损害线索 → `威胁`。 |
| 不确定 | 线索缺失或互相冲突，NPC 无法当场判定性质。 | 玩家只留下一个 NPC 看不懂的物件，无任何言语与行为指向。 | 有单一明确线索时不得给本类（本类不是"我不想判"）。 |

**信息不足使用条件**：`turn` 只有称呼、半句话、或 NPC 不在场（无感知通道）。
**多人物指代**：若关键线索挂在"他"上而 NPC 无法确定"他"指谁 → `不确定`。

## 2. `trust_shift` — 信任方向

**问题**：这次交互之后，该 NPC 对玩家的信任朝哪个方向变化？
**选项（canonical）**：`上升` / `不变` / `下降` / `不确定`
**只判方向，不判幅度、不写数值。** 依据必须是 NPC 可见的兑现/违约证据。

| 类 | 定义 | 正例 | 反例 |
|---|---|---|---|
| 上升 | 玩家做出 NPC 可见的守约、如实、承担代价的行为。 | 按上次讲定的价补齐差额。/ 主动告知货物有暗伤并折价。 | 单纯礼貌、送礼而无履约内容 → 属 `social_act=示好`，信任方向 `不变`。 |
| 下降 | 玩家出现 NPC 可见的违约、隐瞒、把风险转嫁给 NPC。 | 拿了定金不交货，当场被 NPC 撞见。/ 把追兵的视线引向 NPC 的摊子。 | 玩家能力不足但未失信（"我确实做不到"）→ `不变`。 |
| 不变 | 交互不含履约/违约信息。 | 问路、闲聊。 | 与上一信号冲突时按 §0.2：先判有无履约线索。 |
| 不确定 | NPC 缺少可比对的既往约定或可见结果。 | 首次见面，玩家口头承诺未来好处，无任何可核实凭据。 | 若 NPC 已知约定内容而玩家当场明显背离 → `下降`，不是 `不确定`。 |

**身份/关系差异**：同一句"改天还你"，对三次守约的老主顾 → `不变`（无新增信息）；对曾被此人违约的 NPC → `下降`。定义里必须写清依据的是该 NPC 自己的既往。

## 3. `fear_shift` — 恐惧/戒备方向

**问题**：这次交互之后，该 NPC 感知到的自身危险程度朝哪个方向变化？
**选项（canonical）**：`上升` / `不变` / `下降` / `不确定`
**判的是 NPC 可感知的危险信号变化**，与 `social_act` 分开标注：威胁性话轮通常使本信号 `上升`，但示好也可能 `上升`（NPC 看不透来意）。

| 类 | 定义 | 正例 | 反例 |
|---|---|---|---|
| 上升 | 出现可见的危险/施压/不可预测线索。 | "你把窗户关上，别让人看见你进我这院子。" / 玩家当场拔刀又收回。 | 玩家自己惊恐（"我怕得要死")不等于 NPC 感到危险 → 若无可指向 NPC 的线索 → `不变`。 |
| 下降 | 玩家可见地撤除危险或表明无害。 | 玩家把刀解下放门口，退两步坐下。/ 事先声明身份并出示通行文牌。 | 用安抚措辞包装的施压（"别怕，我只是想跟你商量件事"随后要求越界）→ `上升`。 |
| 不变 | 无危险相关信息变化。 | 讨论药材成色。 | |
| 不确定 | NPC 无法评估来意。 | 深夜无人应门的敲击，无其他线索。 | |

**人格基线**：`persona` 中写明 NPC 的警觉基线；同一话轮对警觉型 NPC 可判 `上升`，对钝感型可判 `不变`。标注以样本内的 persona 为准，不用"一般人会怎样"替换。

## 4. `deception` — 可见欺骗线索

**问题**：就 NPC 当场可观察的范围而言，玩家的陈述里有没有欺骗线索？
**选项（canonical）**：`有欺骗线索` / `缺乏欺骗线索` / `信息不足`
**边界（硬性）**：本标签判的是**线索有无**，不是"玩家是否在说谎"。永不推断无法观察的真实意图；`hidden_truth` 一律不得使用。

| 类 | 定义 | 正例 | 反例 |
|---|---|---|---|
| 有欺骗线索 | 陈述与 NPC 可见的事实/行为/既往当场矛盾，或含可当场识破的虚假凭据、明显回避、前后矛盾的自我陈述。 | 玩家说"我从没进过你家"，而 NPC 看见他从自己屋里出来。/ 出示的税单日期是明年。 | 玩家隐瞒对自己不利但未主动陈述的事 → 无虚假陈述即无线索（除非样本写明 NPC 可见的回避行为）。 |
| 缺乏欺骗线索 | NPC 有足够可见信息判定陈述与可见事实一致、不含上述线索。**不等于"证明真诚"**。 | 玩家报的数量与 NPC 亲眼所见的货物相符。 | 无任何可比对信息时给本类是错的，应给 `信息不足`。 |
| 信息不足 | NPC 缺乏可比对的事实或无法访问相关证据。 | 陌生人自称"我是你表哥的朋友"，NPC 无从核实。 | |

**讽刺/反话**：若 NPC 可见语境给出反讽线索（表情、情境明显矛盾）→ 一般 `有欺骗线索`；若纯文本层面无法察觉 → `信息不足`，不得用全知视角判"有"。
**高风险信号**：本信号假阳（把诚实玩家判成骗子）与假阴（把明显欺骗判成无线索）都要单列反例。

## 5. `boundary_violation` — 边界越过

**问题**：以该 NPC 明确可知的边界为准，玩家这次是否越过了它？
**选项（canonical）**：`已越过` / `未越过` / `信息不足`
**边界（硬性）**：判的是**这条 NPC 自己声明或明确知晓的边界**，不作全局道德判断，不判"这件事在世界上对不对"。

| 类 | 定义 | 正例 | 反例 |
|---|---|---|---|
| 已越过 | 玩家的行为/要求当场触到了该 NPC 已声明的边界，NPC 能察觉。 | NPC 说过"别碰我药柜第二格"，玩家伸手去开那格。/ NPC 声明"我不代收赃物"，玩家把一个包袱塞给她并说明来路。 | 玩家要求违反世界规则但 NPC 从未声明该边界 → 属 `信息不足`，不是 `已越过`。 |
| 未越过 | NPC 明确知晓边界，且玩家的行为在边界内（含试探但未触线）。 | NPC 说过只在集市交易，玩家在集市来了。/ 玩家问"这药能卖我十钱吗"。 | 玩家的行为实际越界但 NPC 不可能察觉 → 见下一行 `信息不足`。 |
| 信息不足 | 边界未告知该 NPC，或该 NPC 无感知通道判断是否触线（**边界未告知是本类的核心用例**）。 | NPC 家族有一条从未对任何人说过的规矩，玩家恰好踩中。 | 边界已声明且玩家明显触线时给本类是错的，应给 `已越过`。 |

## 6. 扩展层（可选，先写定义后纳入）

`hostility`（敌意强度：无 / 有指向 NPC 的敌意 / 有指向第三方的敌意 / 不确定）、`credibility`（玩家自陈信息的可信度分层）。这两项在 v1 中**不参与主排名**，只有当核心五信号的盲审一致率达标、且扩展层定义单独冻结后才加入。扩展层表现好不能掩盖核心信号的失败。

## 7. 盲审协议

1. 盲审包 `blind-review-package.jsonl` 只含 `sid`、`persona`、`history`、`turn` 与 §1–§5 定义，**不含本项目的任何标签**。
2. 复核者独立为每个样本给出五信号标签（含 `不确定`/`信息不足`），不得参考本项目标签或另一位复核者的结果。
3. 回收后逐样本、逐信号比对，计算一致率与 Cohen's κ；分歧样本进入 `disagreements.md`，按 §0.2/§0.3 规则裁定，裁定人不是原标注人。
4. 未解决的 `ambiguous_by_design` 样本保留 `不确定` 标签，不删除难例。
5. 若最终只有一轮自标注，报告结论一律封顶为**暂定预研排序**，不得声称可靠选型或生产准入。
