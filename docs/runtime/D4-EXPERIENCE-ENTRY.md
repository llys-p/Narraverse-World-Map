# D4 固定本地体验候选入口

这是独立 World Map 的本地体验候选，基于已验生产候选 `b7e5a9e7c131ee79acd017276ff62910a549d5ad`。不属于 Narraverse 正式平台。长历史仍有几十秒等待，[性能问题 #3](https://github.com/llys-p/Narraverse-World-Map/issues/3)开放跟踪，尚未认定日常性能合格。

## 启动

1. 安装 Node.js 20 或更新版本（本机核验用24.14.0）。
2. 在本源码目录双击 **Start-D4.cmd**，保留终端窗口。
3. 等待窗口出现 `"status":"ready"`；长历史恢复可能需要等待，不要重复启动。
4. 打开 [地图](http://127.0.0.1:18325/runtime-map.html) 或 [村庄](http://127.0.0.1:18325/runtime-village.html)。只在这一个地址体验。

固定配置：仅本机127.0.0.1:18325、scene-survival-village、seed42、允许合法命令写档、关闭开发者心智检查器。若18325已占用或数据目录被锁，启动会报错；不要终止其它服务、改用旧18324或删除锁。

## 一条可以亲手体验的闭环

本机已建立一个未进行玩家动作的新隔离世界（修订0/tick0）：玩家在村庄，20份私粮；未导入任何旧世界。页面上的真实回执才是操作结果，不用反复点击或另开启动窗口。

1. 打开[村庄](http://127.0.0.1:18325/runtime-village.html)，给猎人「赠1份口粮」。本人私粮减少1，猎人出现「我记得，你给过我一份口粮」。
2. 点击「返回世界地图」。若要观察真实日结，在「让世界运行」选择「1天」，点击「推进世界时间」，等待真实回执。活着的玩家会消耗本人私粮；猎人的规则与个人记忆仍由同一世界维护。此步是可选观察，不是进入森林的前置条件。
3. 回到村庄点击「前往森林」，完成后点击「查看森林场景」；也可从地图的旅行入口抵达，再点「进入森林场景」。
4. 点击「查看狼群并发起遭遇」。遭遇期间只用攻击、逃跑或取消按钮，其他世界动作会被暂停。沿当前seed42新世界的窄场景，可攻击至页面显示胜利；实际伤害和结果以服务回执为准。
5. 森林页的「返回世界地图」只切换页面，不会让人物返村。到地图后，在「前往」选「村庄」再点击「旅行」，等待回执；再点「查看村庄场景」。猎人的收粮记忆应仍在。
6. 刷新页面不会推进世界时间。在启动窗口输入`quit`正常关闭，再次双击同一份`Start-D4.cmd`，检查人物、位置、私粮、战斗结果和收粮记忆仍保留。

### 等待与异常

- 提交期间按钮暂停、出现「正在提交」是等待权威事务；长历史可持续几十秒。此轮优先功能闭环，不以等待较久判为丢档。
- 连接中断且结果未确认时，使用页面「重试同一请求」。不要再造一个新动作来代替确认，也不要删浏览器待确认记录或存档。
- 「返回世界地图」是页面导航；「旅行」才改变角色位置并耗时。
- 休整只按既有规则降低疲劳，不承诺回血；给粮从玩家私粮扣，不借公仓或NPC私账。
- 本入口没有接入模型对话，也没有接入正式Narraverse平台；展示的是现有World Runtime玩法。

## 正常关闭与重开

1. 等当前动作返回；在启动窗口输入 **quit** 并按回车。
2. 等待出现 `"status":"stopped"`、服务退出后，再关闭窗口。
3. 下次再次双击同一份 **Start-D4.cmd**，会读取同一目录，继续这个世界。

动作成功会经原服务提交路径保存；quit负责正常关闭并释放锁。不要用任务管理器强杀代替正常关闭，也不要在保存中关闭窗口。异常中止后的档或锁问题需先诊断，不提供自动清锁或重置。

存档位于本源码目录的 **artifacts/d4-daily/world**，属于被Git忽略的本地数据。重新拉代码不等于备份存档；不要删除该目录来“修复”。不同工作树的同名目录是不同世界；移动/复制真实存档另行处理。

如果目录已经存在，却没有正式 `service-commit-r*.json` 文件，启动器会停止并提示保留目录供诊断。这包括空目录、初始化中断后仅有临时文件等情况，不能当作正常重开；不会隐式建立默认 profile 世界。正式文件是否完整、锁是否冲突，仍由原服务严格检查。
