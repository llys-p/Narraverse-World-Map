# D4 固定本地体验候选入口

这是独立 World Map 的本地体验候选，基于已验生产候选 `b7e5a9e7c131ee79acd017276ff62910a549d5ad`。不属于 Narraverse 正式平台。世界活动只在这个入口显式开放为开发者全知观察，并醒目标注为非玩家/角色知识；默认服务关闭活动接口，心智检查器仍关闭。长历史仍有几十秒等待，[性能问题 #3](https://github.com/llys-p/Narraverse-World-Map/issues/3)开放跟踪，尚未认定日常性能合格。

## 启动

1. 安装 Node.js 20 或更新版本（本机核验用24.14.0）。
2. 在本源码目录双击 **Start-D4.cmd**，保留终端窗口。
3. 等待窗口出现 `"status":"ready"`；长历史恢复可能需要等待，不要重复启动。
4. 打开 [地图](http://127.0.0.1:18331/runtime-map.html) 或 [村庄](http://127.0.0.1:18331/runtime-village.html)。只在这一个地址体验。

固定配置：仅本机127.0.0.1:18331、scene-survival-village、seed42、允许合法命令写档、`--inspect-mind false`、`--inspect-activity true`。该活动区会展示最近窗口内的真实历史事实，不读取玩家待确认请求，不输出原始私账/计划/记忆。若18331已占用或数据目录被锁，启动会报错；不要终止其它服务、改用18325/18327/18324或删除锁。本树每个地点页区分正在查看的地点与玩家实际位置，查看不会自动旅行；地点活动仅展示同地点的真实记录。

地图活动区沿用“人物”筛选器：选中人物后显示其当前状态，以及最近事实窗口里的成功、拒绝、未行动、日结和等待结果数量；“当前状态”取与地图同修订的快照，“最近事实”保留事件记录的原始地点。人物统计覆盖所选人物全部最近活动，不随“地点”筛选变化，也不代表完整生涯；选择“全部人物”时显示选择提示并隐藏单人卡。现行规则仍是村长、猎人、商人固定在村庄，只有玩家按真实旅行记录移动，本功能没有新增NPC移动。

## 可选：旧的一日活动观察流程

以下保留为开发者活动面板的可选体验说明，不属于本轮地图到地点导航验收要求。

首次启动会在本源码树的 `artifacts/d4-daily/world` 首次新建隔离世界。该目录不是18325/18327用户世界的复制或迁移。打开[本候选地图](http://127.0.0.1:18331/runtime-map.html)后，活动区会醒目标注为开发者全知观察，不代表玩家或角色已经知道这些信息。

1. 在本候选地图打开村庄场景，赠给猎人1份口粮；以服务回执确认提交成功。
2. 返回地图，选择推进1天并等待真实回执。
3. 查看世界活动：按人物筛选行动与日结消费，按地点筛选已知村庄/森林事实；检查玩家旅行起止、遭遇攻击或逃跑及真实伤害、交易数量和当天tick区间。日结包括重要人物的0份口粮记录，以及注明总量/可用量/保留量的狼群群体统计。
4. 刷新后活动列表应保持同一修订，不推进时间。要正常关闭，在启动窗口输入`quit`；再次启动时这是读取本候选自己的隔离数据目录。

## 交易与一天日结

刚创建的默认场景 seed42 中，玩家有20份私粮、0金币；初始粮食买价10、卖价5。先看「我的金币」「我的口粮」和当前报价，余额为0时直接买粮会被规则拒绝。

地图交易区会随商品/数量显示预计买入总价、本人金币与可卖库存；当前余额不足时禁用买入，库存不足时禁用卖出，数量必须为1至页面显示上限的整数。修改输入只更新提示，不提交交易。按钮可用时仍需明确点击，最终按完成时价格与服务端规则结算；这份预估不保证公仓库存、公共支付能力或其他规则均满足。提交中、读数不可用等原有禁止条件仍优先。

下面是一组从初始状态体验交易和日结的操作：

1. 在地图的公仓商品选择粮食，数量4，点「卖出」；完成后金币20、私粮16。
2. 数量改为2，点「买入」；完成后金币0、私粮18。每笔买卖各推进1tick（10分钟），以完成时价格结算。
3. 选择「1天」并明确推进；跨过一次日结后，玩家消费本人私粮1份，剩17份、金币仍0，tick146。
4. 世界活动选「玩家」，查看卖出、买入、推进成功与一次日结；刷新不会再次消费。正常quit后恢复同一世界，钱粮和活动应保持。

买卖存在价差，这组操作加上日结共减少3份初始存粮。已有世界按当前余额、报价和实际回执操作，不能直接套用上面的初始数值。该流程不保证NPC获得口粮；NPC未行动、消费0和饥饿增加会按真实记录显示。

## 地图与地点导航

地图可分别打开村庄和森林查看页；打开、返回地图和刷新都不会旅行或推进时间。地点页同时标明正在查看的地点和玩家实际位置。体验现有玩法时，可在村庄确认同地点人物与赠粮条件，明确赠粮后点击既有旅行按钮前往森林；在森林使用既有遭遇操作后，可先查看村庄（玩家仍在森林），再点击原有「返回村庄」旅行按钮。返回地图会继续读取同一服务世界。地点活动只显示地点明确匹配当前页的记录；地点未知的历史记录不归给村庄或森林，需回地图查看。

旧D4E3体验树此前核验过赠粮、森林遭遇、返村和关闭重开。那些是复用的历史证据，不证明本树18331候选已运行或已验证；本树活动投影只以本轮限定测试及中控独立核验为准。

### 等待与异常

- 提交期间按钮暂停、出现「正在提交」是等待权威事务；长历史可持续几十秒。此轮优先功能闭环，不以等待较久判为丢档。
- 连接中断且结果未确认时，使用页面「重试同一请求」。不要再造一个新动作来代替确认，也不要删浏览器待确认记录或存档。
- 「返回世界地图」是页面导航；「旅行」才改变角色位置并耗时。
- 休整只按既有规则降低疲劳，不承诺回血；给粮从玩家私粮扣，不借公仓或NPC私账。
- 本入口没有接入模型对话，也没有接入正式Narraverse平台；展示的是现有World Runtime玩法。

## 正常关闭与重开

1. 等当前动作返回；在启动窗口输入 **quit** 并按回车。
2. 等待出现 `"status":"stopped"`、服务退出后，再关闭窗口。
3. 下次再次双击同一份 **Start-D4.cmd**，会读取同一目录，继续这个世界。

动作成功会经原服务提交路径保存；quit负责正常关闭并释放锁。不要用任务管理器强杀代替正常关闭，也不要在保存中关闭窗口。异常中止后的档或锁问题需先诊断，不提供自动清锁或重置。

存档位于本源码目录的 **artifacts/d4-daily/world**，属于被Git忽略的本地数据。重新拉代码不等于备份存档；不要删除该目录来“修复”。不同工作树的同名目录是不同世界；移动/复制真实存档另行处理。

如果目录已经存在，却没有正式 `service-commit-r*.json` 文件，启动器会停止并提示保留目录供诊断。这包括空目录、初始化中断后仅有临时文件等情况，不能当作正常重开；不会隐式建立默认 profile 世界。正式文件是否完整、锁是否冲突，仍由原服务严格检查。
