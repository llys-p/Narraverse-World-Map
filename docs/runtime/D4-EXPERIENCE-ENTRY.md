# D4 固定本地体验候选入口

这是独立 World Map 的本地体验候选，基于已验生产候选 `b7e5a9e7c131ee79acd017276ff62910a549d5ad`。不属于 Narraverse 正式平台。长历史仍有几十秒等待，[性能问题 #3](https://github.com/llys-p/Narraverse-World-Map/issues/3)开放跟踪，尚未认定日常性能合格。

## 启动

1. 安装 Node.js 20 或更新版本（本机核验用24.14.0）。
2. 在本源码目录双击 **Start-D4.cmd**，保留终端窗口。
3. 等待窗口出现 `"status":"ready"`；长历史恢复可能需要等待，不要重复启动。
4. 打开 [地图](http://127.0.0.1:18325/runtime-map.html) 或 [村庄](http://127.0.0.1:18325/runtime-village.html)。只在这一个地址体验。

固定配置：仅本机127.0.0.1:18325、scene-survival-village、seed42、允许合法命令写档、关闭开发者心智检查器。若18325已占用或数据目录被锁，启动会报错；不要终止其它服务、改用旧18324或删除锁。

## 从哪里开始

**第一次会建立一个新的隔离世界**，从村庄起步；没有导入此前赠粮/战斗/战后存档，也不会改变旧18324里的世界。

- 村庄：选择同地点人物，给猎人一份自己的口粮，查看其本人收粮记忆。
- 地图：查看自己的库存与世界读数，使用现有旅行和时间推进命令。
- 森林：通过现有旅行入口抵达，按页面提供的遭遇/战斗操作继续；返回村庄仍属于本入口的同一个世界。
- 查看、刷新和页面往返不自动推进世界时间；实际动作按既有规则耗时并持久保存。

这是已有功能的入口说明，不代表本轮重新运行了完整故事或浏览器验收。

## 正常关闭与重开

1. 等当前动作返回；在启动窗口输入 **quit** 并按回车。
2. 等待出现 `"status":"stopped"`、服务退出后，再关闭窗口。
3. 下次再次双击同一份 **Start-D4.cmd**，会读取同一目录，继续这个世界。

动作成功会经原服务提交路径保存；quit负责正常关闭并释放锁。不要用任务管理器强杀代替正常关闭，也不要在保存中关闭窗口。异常中止后的档或锁问题需先诊断，不提供自动清锁或重置。

存档位于本源码目录的 **artifacts/d4-daily/world**，属于被Git忽略的本地数据。重新拉代码不等于备份存档；不要删除该目录来“修复”。不同工作树的同名目录是不同世界；移动/复制真实存档另行处理。

## 核验范围

本轮仅核验新启动配置对应的CLI/HTTP读链与同一临时目录的正常退出/重开一致性，未作真实浏览器或视觉巡检；未重跑H7、完整故事或长历史。业务与持久化基础复用D4P5原证据。默认体验目录留给用户首次启动，不在交付时启动常驻服务。旧18324、正式平台、原始私档保持。
