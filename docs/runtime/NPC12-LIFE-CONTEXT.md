# NPC12：猎人日常行动的私人对话上下文

2026-10-26（Asia/Shanghai）。从NPC11 `aa10926f8e0019aa66e61ed2e9a4c757a8ed9a5e` / 草稿 #19 建立 `codex/npc12-life-context-20261026`。

## 功能与边界

原Provider知道猎人的工具、关系、私人资产和社交经历，但没有收到本人保存的行进意图、当前计划步骤和最近执行结果。本片在fixture5的私人对话上下文增加 `activity`，并传递本人当前饥饿读数，让模型有依据解释生活行动。

- `intent`：最近记录的行进动作、目的地类别、记录时间、抵达/前往/等待更新/停止，以及安全或工具原因的改道。目的地是工作点、粮摊、歇脚处或避让，不发送他人坐标。准备或抵达不表示已经执行。
- `plan`：本人已保存的计划种类、当前步骤和ready/blocked状态；不发送完整决策候选、内部评分或knowledgeFingerprint。ready不保证成功，blocked不提供通用确切原因。
- `lastResult`：配对的本人最近决策及实际执行结果，包含动作、成功/拒绝/无行动、时间及当次钱包/粮食变化。准备阶段没有结果；不配对、未来或不合法输入不输出成功结果。当前库存和钱包仍从self读取。

实际工作后、下一次行进意图更新前，旧意图标为awaiting-review，不能说仍在准备同一次工作。工具不可用或害怕附近玩家时，按原移动规则改道；共享原 `socialTravelTarget`，不据隐藏的实际工具归属补全知识。地点常量提取到无依赖的 `npc-village-sites.mjs`，保持原坐标与旧导出，避免读取层引入规划器循环依赖。

只读取已保存的本人状态，不重跑决策、不访问未发布请求配置、不读他人资产或当前隐藏公共库存。`activity`先由核心白名单提取，再在Provider边界重建白名单，未知字段丢弃；投影幂等。新字段不写存档、不进入公开投影，也不增加memoryRefs来源或模型执行权限。旧fixture1～4没有新增字段，世界规则与旧存档结果保持。

这提供的是表达依据，不能保证模型正确理解或自然回答。请求仍受原32KiB上限约束；新增上下文会增加输入长度，真实token、费用和速度未测。没有完整长期生活循环、通用行动规划、无限记忆或新自主行动；工作机会仍有限，128条命令容量和长期性能限制仍存在。2.0仅作参考，没有导入记忆模块。
