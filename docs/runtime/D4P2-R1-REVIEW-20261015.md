## 优化决策与停止点

只采纳一项：**保留校验语义的canonicalJson校验/编码合并遍历**。原`cloneData`负责有限数、普通记录/描述符、稠密数组、循环与深度预算等校验，不是可以直接删去的冗余。共享`put`继续保持defineProperty写入，避免原型键/继承setter等语义改变；本次不同时优化所有复制路径。

data-contract是所有profile共享的公共底座，不能声称改它天然只影响scene。下一项要求有效输入逐字节编码等价、非法输入拒绝/错误码及getter不执行等边界保持，并保留完整外部存档审计与重演。
