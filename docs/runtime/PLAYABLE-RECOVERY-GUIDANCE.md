# 任务期限、失败与重接引导

## 给玩家看

任务到了期限的最后一刻，页面会说明推进世界时间将导致失败。如果任务已完成且玩家在村庄，可以立即领取；在村外则提示返回途中会推进时间，并可在回村后重新接取。进行中任务可选择放弃并重接，也可先查看是否有不推进时间的可用行动。

行军或战斗时，提示保留当前操作约束，不保证已开始的行军步可以被即时取消。失败与主动放弃会分别说明；玩家死亡或额度耗尽时，引导保留原存档并另开旅程。

只剩一次命令时，未能在村庄领取的任务无法同时完成并领取；已完成且身在村庄的任务仍可用最后一次命令领取。提示本身不会提交动作。

若猎人本人在玩家当前视野中且已倒下，任务提示不会继续要求向他赠粮或帮他修理，并说明可放弃任务、保留存档或另开旅程。人物不在公共视野中时，页面不会推断他的生死或位置。若任务已经达到领取状态，页面仍按当前真实状态提供领取，不因看到猎人倒下就撤销奖励。
