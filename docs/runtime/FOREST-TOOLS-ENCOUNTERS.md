# 森林工具与可选狼迹

## 给玩家

运行本分支的 `Start-Forest-Journey.cmd`，等待 ready 后打开 `http://127.0.0.1:18356/demo-runtime.html`。这是包含 PR41 借工具支线的独立新旅程；同一入口恢复本段旅程，`Start-Forest-Journey-New.cmd` 另开旅程并保留旧档。原借工具入口继续原规则。Windows 启动器尚未实机验证。

借到工具后，走近森林的林间歇脚处 (16,7)，即可选择：

| 行动 | 世界时间 | 真实变化 |
| --- | --- | --- |
| 用工具采枯枝 | 30分钟 | 取得1捆枯枝；工具耐久−10，疲劳+25；耐久至少40才能开始 |
| 生火歇脚 | 30分钟 | 消耗1捆枯枝，疲劳最多−200；不回血、不补粮 |
| 观察狼迹 | 10分钟 | 开放主动迎战选项；不会开始战斗或占用狼 |
| 绕开狼迹 | 不耗时 | 保存绕开的选择；不损害关系，不要求战斗 |

枯枝来自当地3捆有限枯落枝条，采尽不刷新，不能卖钱或换粮。没有工具、燃料或已经采尽时，仍可使用原有休整并返村。采集和歇脚都可跳过，主线与守约支线不增加新门槛。工具磨损会保留到实际归还之后，可再靠近猎人帮助修理。

观察后，只有主动点击“迎战森林狼”才进入原有战斗。攻击可能受到反击；“结束遭遇”沿用原有免费退出规则，已经受到的伤害不会回退；也可选择原有1小时逃离。为防止额度耗尽后卡在战斗中，迎战需留下退出额度，遭遇中最后一条命令保留给“结束遭遇”。退出或胜利后，重新观察才能再次挑战。未进入遭遇时，可直接点击“返回村庄”。

耗时行动会推进世界、NPC活动和借期；归还工具还需10分钟。逾期仍会造成原有任务与关系后果，采集不会替你免除旧债。行动完成时再次核对条件，途中死亡不会获得枯枝或扣工具耐久，但已经经过的世界时间仍保存。死亡沿用原旅程规则，可另开新旅程，不自动复活或改写旧档。

本轮58项不同检查通过，涵盖规则、旧玩法、界面回调和真实服务；退出额度补齐后核心与实际服务复跑通过。真实服务的验证结果见下方交接。浏览器画面、移动端布局、键盘/读屏、Windows 启动器与真人体验仍待验；云浏览器无法连接本工作区的回环服务，未搭建隧道或部署。未做新版本长档性能验收，模型调用为0。
