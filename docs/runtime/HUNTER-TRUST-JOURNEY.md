# 借工具探路：可选支线

## 给玩家

帮助猎人后，新任务“借工具探路”解锁。它可以和森林往返一起做，不要求猎狼，也不会挡住第一章主线。任务提供一段有期限和关系后果的行动目标，不额外赠送金币、粮食或战斗加成。

在包含本改动的分支，运行 `Start-Trust-Journey.cmd`，等待 ready 后打开 `http://127.0.0.1:18354/demo-runtime.html`。入口建立独立的新旅程；之后同一入口恢复这段旅程。`Start-Trust-Journey-New.cmd` 另开新档。原 `Start-Playable.cmd` 保留原来的四任务旅程。Windows 启动器尚未实机验证。

1. 完成村庄生计和帮助猎人，在任务板接取“借工具探路”。可同时接取森林往返。
2. 猎人当前可见时，点“查看猎人”。走近人物与歇脚处，选择“请求借工具”；也可以提出修理换借用，接受实际条件、修理、再领取。遭拒绝不代表借出成功。
3. 携带借到的工具到森林。工具会真的离开猎人，影响他工作；工具本身尚无玩家采集或战斗用途。可以不战斗，也可选择挑战，但行动会消耗借期。
4. 返回歇脚处附近，走近猎人并点“归还工具”。返回村庄本身不算交还。最后在任务板领取进展。

借期取自实际约定：普通借用24小时，修理换借用按猎人同意的6/12/24小时条款计算。页面显示世界时间倒计时；现实等待不消耗借期。**归还动作需要10分钟，必须在截止时刻前开始，并在截止时刻或之前完成。** 到最后一刻才点击归还已经太晚。

提前归还但尚未探路，会重置本次借用步骤，可以重新借用。接任务前的借用不计入新任务，偷抢工具也不计入。逾期会让支线失败，并保留真实关系后果；仍可实际归还，处理关系后重接。放弃或重接任务不会替你归还工具或清除旧债。玩家看不到猎人时，任务板不会提供他的隐藏位置。

当前仍是有界原型：新支线没有新增人物、森林场景、美术、音效或工具技能；实际浏览器布局、键盘/读屏、Windows及真人体验待验。新版本长历史恢复未测，不据此宣称流畅度达标。模型调用为0。
