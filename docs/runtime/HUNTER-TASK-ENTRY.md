## 给玩家看

“帮猎人渡过难关”进行中，如果猎人当前可见且存活，任务卡会提供“查看猎人”。点击打开现有人物卡，玩家可以查看对方状态并自行选择修理、交谈或前往；按钮本身不会推进时间或代替玩家行动。猎人离开视野、倒下或任务结束后，入口会消失。
