1. **采集已经落盘但页面没收到回执**：页面保留原请求并禁止另发；页面客户端与服务重开后重试，只有一捆枯枝、一次工具磨损、一次回执展示。

### 桌面实机验收入口

在该候选的完整源码目录中，安装Node.js 24或更新版本，并使用本机已安装的Edge/Chromium，运行 **`Verify-Forest-Playtest.cmd`**。这是验收工具，不是另一个游戏入口。

它只新建隔离合成世界和浏览器profile，使用临时端口，不读取你的真实档、不读取`.env`、不启用语言模型或产生模型费用。默认使用Windows常见Edge路径；其他安装位置可通过 `DEMO_BROWSER_EXECUTABLE` 显式指定。工具不下载浏览器、不架隧道、不部署，也不会关闭其他浏览器或旧实例。

报告路径在终端打印，位于 `artifacts/forest-playtest/run-.../result.json`。可选命令行：

```sh
node scripts/verify-forest-playtest.mjs artifacts/forest-playtest/my-new-run
```

输出目录必须尚不存在，避免覆盖旧证据。工具先核对192份候选游戏文件，再检查浏览器；缺少浏览器则输出 `BLOCKED`、退出码2，在启动服务之前停止。实际失败是 `FAIL`/退出码1；浏览器流程全部执行才可能 `PASS`/退出码0。不要把预检通过或BLOCKED当作游戏验收通过。

有浏览器时，脚本计划用正常按钮输入走完整旅程，核对只读人物卡、实际采集/燃料/磨损、390px窄屏、Tab/Enter结束遭遇、伤害不回滚、返村归还，以及关闭重开后相同世界；生成桌面/窄屏/重开截图。**本环境没有浏览器执行文件，因此这些浏览器步骤尚未实际验证，脚本可能仍需在实机上调试。**窄屏模拟也不等于真手机，键盘退出不等于读屏验收；Windows双击启动仍待实际执行。
