# 森林行动引导与返程反馈（2026-10-29）

## 给玩家

当前已到“借工具—森林采集/歇脚—选择狼迹遭遇—返村归还”的可玩流程；本轮续接PR42，让玩家更清楚地判断下一步和行动代价。入口继续使用 `Start-Forest-Journey.cmd`，端口18356；`Start-Forest-Journey-New.cmd`可另开旅程并保留原档。

- 森林面板现在能直接“走到林间歇脚处”和“普通休整”。没有枯枝也可普通休整；生火仍消耗实际燃料，采集仍磨损实际工具。
- 每个按钮旁显示行动代价和具体不可用原因：疲劳过高、距离不足、缺少枯枝、已观察/已绕开、行军、战斗及额度不足分别说明。疲劳高不再误提示暂停行军。
- 暂停的返村路线显示“继续返回村庄”，复用原订单；正在返回时不再重复下令。没有自动返村、自动休整或自动开战。
- 本次进行中支线有明确借期时，显示剩余时间，以及采集/生火/观察/休整后的剩余时间。归还本身还需10分钟，返程和走近猎人也会耗时；提示不保证来得及，不改变原规则，也不强制禁止玩家冒险。
- 放弃或失败的委托记录不再冒充手中工具的当前借期。例如旧借用归还后又借了一次，但未重接任务，面板会说明旧委托无法确认当前借期。没有从私有NPC状态补读日期。
- “结束遭遇”与“返回村庄”集中在离开区域；战斗最后1次操作提示用于免费结束遭遇。退出不会回血，也不返还已经经过的时间。低于3次操作不能发起行军，但这不是保证3次就能走完全程。

按钮增加可见说明和对应读屏描述，使用可换行布局与至少44px的按钮高度。这里只验证结构和回调，**真实浏览器画面、移动端触控、键盘/读屏、Windows启动仍待验**。现有云浏览器无法连接工作区回环服务，本轮未再尝试同一路径，未架隧道或部署。
