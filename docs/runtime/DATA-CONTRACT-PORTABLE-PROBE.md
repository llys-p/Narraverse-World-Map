# 仓库 AI 可直接运行的短性能样本

用于 [Issue #3](https://github.com/llys-p/Narraverse-World-Map/issues/3) 的源码机制初步对照。**合成样本不代表真实r170开档，也不证明日常性能或规模达标。** 原私有8档未上传；不要使用本机D盘路径猜测云环境已有样本。

在包含本脚本的任务分支/提交下，使用 Node.js 20+ 和 Git，获取完整祖先历史后，在仓库根目录运行：

```text
node scripts/measure-data-contract-synthetic.mjs
```

无npm依赖、无参数、无需凭据或私有存档。脚本仅输出JSON到stdout，不写文件、不启动服务、不访问网络；可由调用者将stdout保存到自己的日志路径。固定150个合成实体、每操作100次、轮换顺序3轮。先核对复制值/规范字符串、getter=0与循环/访问器拒绝，再计时。

参照从Git读取固定2936233426e990857f3c88a39ad58623832419fd和10a2180441fcc9509a6ddd561ac97679f279aa9f的数据合同源码；第三组是当前检出的runtime/core/data-contract.mjs。JSON记录参照SHA及当前文件SHA，报告候选commit=null（工作树可能有未提交改动，不能臆造其精确提交身份）。

浅克隆缺少参照对象或Git不可用时显式退出1，提示REFERENCE_UNAVAILABLE，不自动fetch或改仓库。先取得所列任务分支的完整历史再重跑；缺档/缺历史写“未复现”，不能用其它oracle冒充。

这是单进程短对照，受JIT/GC/系统负载影响；公开的样本、操作、次数与原长存档链不同。任何后续优化仍需完整数据边界、实际持久化/恢复和有界真实工作负载证据。禁止用删校验、改预算、trusted参数、跳过完整重演获取通过；避免重复全量/视觉/旧长链验收。
