入口为 `Start-Playable.cmd`，页面 `http://127.0.0.1:18352/demo-runtime.html`。需要Node24；使用独立fixture6/profile `campaign-playable-village`，不升级旧档。关闭时输入 `quit` 等待 `stopped`。死亡后可用 `Start-Playable-New.cmd` 创建另一个档，原旅程保留；启动器尚未在Windows实机验证。

## 给玩家看的变化

任务板有四项明确目标：工作并买粮、修好猎人工具并赠粮、森林往返、可选猎狼。前三项构成初章；接取、放弃、重新接取和领取均由世界审核。说“我完成了”不会推进任务。第二项认已有的合格工具，领取前再次损坏会撤销达成条件；森林探路允许避战。任务期限为接取后14游戏日。任务奖励为后续委托与称号，钱粮仍来自实际工作/交易，重复领取不会增益。

玩家初始4份粮；不再用大额补给掩盖生计循环。猎人每3日最多获得一次已配置工作机会，共7次；工资由既有经济规则支付，买粮消耗真实钱包与公共库存。农业沿用生产账本，60名农人每日生产90份粮。当前是有限村庄原型，不是无限就业/动态任务系统。

NPC准备计算分为任务重要4刻、近处12刻、远处24刻。本人资源、工具认知、工作请求、决策、安全范围或游戏日变化会提前更新。真实移动仍每4刻至多一格，工资、进食、疲劳、伤害与期限仍按原权威规则结算；不把屏外时间直接跳过。休息沿用既有需求与日结，不把NoAction写成实际Rest行动。

私人对话可读取本人最近8条已配对的生活结果；世界最多保留16条。过去领薪/买入增量与现在钱包/库存分别提供。生活记录不进入公共任务投影，不新增可引用的情景记忆来源；语言仍不能自行转移资源或完成任务。

## 性能与验收边界

复用既有渲染器、地图、工作/交易/战斗、不可变世界证明、单写者和恢复流程，没有引入新引擎。单刻去掉一层重复整包复制，仍先检查数据描述符和规则身份。新档恢复服务日记时复用既有确定性后继核验，锚点与末态仍独立完整审计；外部存档没有可传入的跳过校验开关。

新档命令预算512，持久文件最多513；旧档保持128/129。该预算不是无限游玩承诺，行军和失败命令也计入。较长模拟与开档仍可能等待多秒。HTTP读取响应、权威结算时间、冷开档时间与浏览器帧率分别评价；不能把读取快当作结算快。

本批浏览器限制：本机缺Chromium，官方下载安装失败；云浏览器不能访问本机隔离服务。真实画面、60FPS、点击100ms视觉反馈、Windows启动器及30–60分钟真人内容时长均待验。30–60分钟只是原内容设计目标，尚未达到可声称的时长验收。源码/HTTP与离线玩法证据不能替代这些项目。
