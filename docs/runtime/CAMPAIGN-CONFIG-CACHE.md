## 给用户看

本片针对推进时间和重新打开长档时，同一套配置反复建立初始世界的成本。任务奖励、NPC生活规则、远近准备频率和经济规则保持既有设计。速度以本机固定七日场景、完整审计及实际worker/HTTP结果为准；接口耗时不等于画面帧率。
