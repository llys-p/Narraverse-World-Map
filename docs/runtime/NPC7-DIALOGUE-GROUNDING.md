派生层只读取原来允许发送的 NPC 私有视角，不查询世界的真实持有人或其他人的记忆。未知失物仍为未知；不会通过新增字段让 NPC 获得未目击事实。原来至多12条近期/重要记忆、8轮交谈和32KiB入口预算保持；自定义的未声明字段不会发给模型。

`runtime/service/npc-dialogue-grounding.mjs` 提供同一个准备函数，Provider和评测器都传入本轮原话。转换重复应用结果不变；报告记录的上下文与实际请求一致。源码指纹包含新派生层、有界文字解析器和时钟常量。

## 仍由模型完成的部分

这不是固定台词表。回复仍来自所选模型；本层不改写模型措辞、不伪造或补齐模型返回的行动建议。完整句式提示只覆盖少量明确表达，未覆盖的表达仍交给模型理解或追问。既有结构/引用校验、签名、预览、交谈确认和单独行动确认继续生效。

新的提示不能保证模型每次正确使用事实。结构有效但内容错误仍有可能出现，真实质量须另测；不能把“程序算对20分钟”称为“模型已经不会说错”。完整上下文更长，也可能更早达到原有输入预算，未测实际token成本变化。
