# 1. 最初的念头：不是“意图识别”，而是给 NPC 装一个大脑

最初的兴趣点是“NPC
的意图识别”：判断他想攻击、逃跑、合作、撒谎、试探，或者他对玩家究竟是什么态度。继续往下追问后，真正想要的东西变得更大。

因此，“意图识别”只是一小块。更完整的目标是让重要 NPC
拥有自己的认知循环：他看见什么、怎样理解、在乎什么、害怕什么、想要什么、准备怎么办，以及这次经历怎样改变未来的他。

# 2. 世界只有一个，但每个人活在自己的“版本”里

一个非常重要的类比来自现实中的多 AI 协作：把同一个项目交给 4 个不同
AI，它们面对的是同一个客观项目，但会因为上下文、关注点、推理方式和已有经验不同，形成不同见解。

游戏世界也可以这样：World State 是唯一真实世界，但每个 NPC
只接收到自己能够看到、听到、记住或推测到的那部分。

世界事件 → 感知过滤 → 个人理解 → 意图 → 行动 → 新世界事实

同一场事件中，甲亲眼看见，乙只听到传闻，丙完全不知道，丁看见了却认错了人。于是四个人面对的是同一个世界，却拥有四个不同的主观世界。

# 3. NPC Brain 的循环：每次“读到重要信息”都要过脑子

“做决策”不等于每次收到信息就立刻采取外显动作。一个完整的大脑还可以选择观察、记录、改变看法、提高警戒、修改计划、等待时机。

| 阶段 | NPC 内部问题                                           |
|------|--------------------------------------------------------|
| 感知 | 我实际看见、听见、收到什么？哪些信息对我不可见？       |
| 解释 | 这件事对我意味着什么？它和过去发生过的事有什么关系？   |
| 动机 | 我现在最需要解决什么？生存、关系、责任、利益还是理想？ |
| 决策 | 我有哪些可行做法？哪一种最符合处境、性格、目标和经验？ |
| 意图 | 我决定准备做什么，或者暂时不做什么。                   |
| 执行 | 把意图交给世界规则验证。模型不能直接修改世界。         |
| 学习 | 结果进入记忆，并可能改变关系、习惯、策略乃至长期人格。 |

# 4. 主要人物、次要人物与背景人口

让每个 NPC 永远调用完整 AI 大脑并不现实，也没有必要。更自然的是分层。

| 层级             | 思维深度                                                                           |
|------------------|------------------------------------------------------------------------------------|
| 背景人口         | 以统计、群体、资源、生态方式存在；不持续运行独立 Brain。                           |
| 次要人物         | 有身份、简单需求、关系和目标；主要由规则、Utility、行为模板驱动。                  |
| 主要人物         | 有完整记忆、主观认知、复杂动机、长期目标、经验规则和成长轨迹；复杂情境可调用模型。 |
| 核心角色（可选） | 长期保留更完整人物历史和上下文，适合主角团、宿敌、重要盟友等。                     |

人物层级不一定永久固定。一个普通酒馆老板如果被玩家反复接触、卷入重大事件，或者由“幕后导演”指定，就可以升格为主要人物。升格时可以根据已有事件记录重建他的关系、过去经历和人物历史。

# 5. 人格：稳定底色 + 经历塑形

偏好的方向不是“几个性格数值决定一切”，而是 C + D
的组合：核心人格保持连续性，经历则改变角色的处世方式。

核心人格可加入荣格十六型常见的四个连续维度，但不把人物粗暴固定成某个四字母类型：

E ↔ I　外向 / 内向  
S ↔ N　实感 / 直觉  
T ↔ F　思考 / 情感  
J ↔ P　判断 / 感知

四轴更像“人格重力场”，长期稳定、缓慢漂移。真正高频变化的，是经验、习惯、策略、关系认知和情绪状态。

# 6. 动机：像马斯洛，但不要把人做成阶梯机器

人物行为动机可以从家庭背景、生存条件、身份责任、社会关系、目标理想等来源产生。需求层级可以借鉴马斯洛式直觉：生理、生存、安全等低层需求通常优先，但人格、责任和信念可以打破顺序。

出身 / 家庭 / 社会条件 → 核心人格与价值观 → 当前生存状态 →
社会关系与责任 → 长期目标 / 理想 → 过往经验 → 当下动机

例如一个想成为伟大骑士的人，饿了三天时通常先找食物；但某些高度忠诚、执拗或理想主义角色，可能在极端情况下牺牲生存利益。重点不是“需求金字塔绝对排序”，而是让每个人有不同底线。

# 7. 行为从哪里来：角色预设“行为倾向 + 行为库”

一个重要灵感是：创建人物时就写出他“通常会怎么处理问题”，而不是让 AI
每次凭空发明行为。

## 上层：行为倾向

例如：保护自己和家人；避免正面冲突；对陌生人先试探；有利益时愿意冒险；不喜欢欠人情；被逼急时可能撒谎。

## 下层：具体行为

例如：观察、试探、交涉、拒绝、撒谎、求助、撤离、雇佣护卫、贿赂、攻击、偷偷调查、帮助熟人。

环境、情绪、需求、关系、当前目标和经验负责“激活”一部分行为，随后再由动机和人格进行排序。

主要人物还可以在现有行为无法覆盖复杂情境时，让模型提出少量新策略，再经过人格、目标、价值观和世界规则审查。某种新策略若反复有效，未来甚至可能沉淀成新的行为习惯。

# 8. 情绪不是开关，而是放大器

“环境或者心情影响行为”是一个很自然的方向。但情绪不应该直接写成“愤怒 \>
80 就攻击”。

同样是愤怒，一个冲动角色可能当场拔刀，一个极度谨慎的角色可能表面忍住、暗中准备报复。情绪推动行动，人格与经验决定推动之后会走向哪里。

因此行为决策可以综合：需求 + 环境机会 + 情绪推动 + 人格倾向 + 当前目标 +
经验修正 + 关系修正。最终公式可以后定，先保留这个概念。

# 9. 幕后导演：制造处境，不替角色写答案

另一个强烈愿望是保留“小说作者 / 幕后导演”的快感。不是把 NPC
当木偶，而是在世界背后安排条件。

例如：某个女商人欠某势力很多钱。导演层可以安排“那个势力今天找上门”，但不直接规定“她必须背叛玩家”。最后她撒谎、求助、拖延、反抗还是投靠，应由她自己的处境和大脑决定。

# 10. Laya 的位置：可用，但它不是“大脑本身”

一开始曾设想依靠 Laya 实现“NPC 大脑”。继续拆解后发现，Laya
更适合作为某个认知脑区，而不是完整控制器。

例如它可以帮助判断：一句话更像威胁、示好、试探还是信息不足；某段行为是否存在欺骗线索；某个交互可能引起怎样的社会信号。

但完整大脑还需要处理：记忆、有限视角、需求、长期目标、行为库、世界约束、成长、人物关系以及计划连续性。即使
Laya 暂时不可用，NPC 仍应拥有一个可运行的“脑”。

因此更合理的关系是：

NPC Brain Runtime  
├─ 感知 / 文本理解：规则、Laya、小模型、LLM（可插拔）  
├─ 记忆与认知  
├─ Needs / Motivation  
├─ Personality / Experience  
├─ Intent / Planning  
└─ World Action Resolver

# 11. 不必真的“一个 NPC 一个 API”，而是一个 NPC 一个独立认知体

理想状态可以像“每个人都接了自己的 AI”，但工程实现不一定要求每个 NPC
拥有独立 API Key 或独立模型。更核心的是每个 NPC 有自己的 Brain Profile
和上下文。

Brain Profile
可以包含：身份、人格四轴、价值观、需求、长期目标、当前目标、记忆、关系认知、经验规则、行为倾向、当前情绪。底层
Brain Provider 则可以替换成规则系统、本地模型、云模型或混合方案。

即使几个 NPC
使用同一个模型，只要他们看到的信息、记忆、目标和关系不同，也会形成完全不同的判断。

# 12. 世界权威边界：模型只能产生 Intent，不能直接改世界

这是整个方向里需要牢牢守住的一条。NPC
大脑可以决定“我要攻击玩家”，但世界运行时必须检查：他有没有武器、距离是否足够、是否清醒、是否还活着、动作是否与当前状态冲突。

Brain → Intent → Action Resolver → Command / Rule Validation → Canonical
Outcome

只有经过世界规则确认，Intent 才变成真正发生的 Action。这样 NPC
可以有主观世界，但客观世界仍保持唯一与确定。

这个系统的目标不是“系统判断 NPC 想什么”，而是让重要 NPC
自己产生他认为合理的想法。

每个重要人物拥有自己的主观世界；世界通过事件向他们提供不同的信息，他们根据自身人格、经历、需求、关系和目标形成解释，再产生意图。行动进入世界后，又成为所有人物下一轮认知的新输入。

它最终可能成为“活世界”上层的人物心智系统，而不是某个单一模型的包装。

# 14. 暂时不要定死的问题

- 人格四轴具体数值范围、初始生成方式以及长期漂移速度。

- Needs / 动机之间究竟采用层级、Utility 分数还是混合仲裁。

- 行为库的 schema：哪些属于行为倾向，哪些属于真正可执行动作。

- 主要人物何时触发模型调用，何时只使用规则。

- 经验规则如何形成、遗忘、被反例修正，哪些创伤或执念可以长期保留。

- 主要人物与次要人物升格 / 降格时如何压缩和恢复记忆。

- 多个动机冲突时，怎样表现犹豫、妥协、延迟、撒谎与两面行为。

- Brain Tick 的触发条件：每条信息、重要事件、固定时间片，还是混合触发。

- Laya 或其他小模型未来究竟适合进入哪些“脑区”。

# 16. v0.2 新的核心原则：复杂度预算，而不是“凡事都工程化”

实际开发时，不应该为了理论上的“完整人格”把每一种低频心理现象都做成专门模块。真正需要工程化的，是高频、可复用、可验证、会长期影响世界状态或角色连续性的部分。

对于低频、难形式化、难测试、收益有限的复杂心理内容，可以让接入的 LLM
读取角色当前的有限视角、记忆、人格、关系、目标和情境，在需要时临时生成解释、策略或心理表达。

先问：这件事值得做成规则吗？  
  
高频 + 高影响 + 可验证 + 需要重放 → 规则 / Runtime  
低频 + 高语义复杂度 + 难验证 + 不直接改世界 → LLM / Model Advisor

这条原则不是“把难题都甩给模型”，而是建立成本意识：只有那些值得长期维护的行为规律才进入规则层，复杂但偶发的心理细节交给模型作为外脑顾问。

可以把它理解为：确定性系统负责骨骼和神经，LLM
负责需要临场组织的思路和语言。不要为一根一年只会动一次的“心理肌肉”单独造一套机械传动。

# 17. 收敛后的 NPC Brain 主干

经过前几轮讨论，NPC Brain
的核心已经可以从“意图识别”收敛为一条连续认知链。

Canonical World Fact  
↓  
Perception Channel  
↓  
Attention Gate  
↓  
Belief / Subjective World  
↓  
Emotion + Memory  
↓  
Needs + Roles + Values + Goals  
↓  
Motivation  
↓  
Behavior Activation  
↓  
Conflict Resolution  
↓  
Intent  
↓  
Plan / Apparent Action  
↓  
Command Engine  
↓  
Canonical Outcome  
↓  
Memory / Learning / Personality Growth

世界事实始终唯一；人物主观理解可以不同。Director 负责制造处境，Character
Mind 负责回应，World Runtime 负责判定“究竟发生了什么”。

# 18. 主观信息管线：感知、注意力、信念与谣言

## 18.1 感知信道

NPC 不应该直接读取完整 World
State。信息必须经过可知性与感知来源进入角色大脑。可能的信道包括：Visual、Auditory、Dialogue、Notice、Inference，以及未来的
Rumor。

来源可信度不能固定写成“亲眼所见永远 1.0、官方公告永远
0.7”。更合理的是由信道可靠度、NPC
对来源者的信任、现有证据一致性、角色偏见和过往经验共同修正。

## 18.2 Attention Gate

并非所有可感知信息都值得深度思考。先用低成本规则判断显著性，再决定是否唤醒完整
Brain。饥饿、生命威胁、当前目标、亲密关系、强烈情绪和重大身份义务都可以提高显著性。

World Events 100 条  
→ Perception 可见 20 条  
→ Attention 真正相关 3 条  
→ Brain 深度处理 1~3 条

## 18.3 Belief：事实与解释严格分离

Belief 底层建议保留连续置信度，而“确信 / 倾向相信 / 怀疑 / 不信”只作为
UI 展示层。每条信念至少应能追溯来源、证据与更新时间。

Belief  
- proposition  
- confidence  
- source  
- evidenceRefs  
- contradictionRefs  
- fidelity  
- transferredHops  
- interpretation  
- lastUpdated

最重要的底线仍然是：Fact ≠
Interpretation。角色可以重新解释过去，但不能改写已经发生的客观事实。

## 18.4 谣言传播与失真

信息被多次转述时，不只“可信度”下降，“细节保真度”也会下降。Fidelity 与
TransferredHops 可以用于模拟模糊、情绪放大和派系偏见。

失真结果必须生成新的 Rumor / Belief，而不是覆盖原始 World
Fact。这样既能出现“越传越离谱”，也不会破坏审计和重放。

# 19. 动机系统：Needs、身份、价值观与人生目标

## 19.1 目标分层

角色目标可以分成远期愿景、策略目标和战术目标。远期愿景不直接产生动作，而是影响中长期目标的优先级；战术目标负责解决当前缺药、缺钱、饥饿等具体问题。

Aspiration 远期愿景  
→ Strategic Goal 阶段目标  
→ Tactical Goal 当前问题  
→ Plan / Action

## 19.2 Role / Obligation

人物不仅“有性格”，还同时扮演父亲、卫兵、朋友、领主、债务人等社会角色。每个
Role 可以带有 Obligation，并在情境中与其他身份发生冲突。

当角色为了一个身份违背另一个身份义务时，决策不应在动作完成后归零，而应留下心理后果，例如
Guilt、Shame、Resentment、IdentityConflict 或 MoralDebt。

心理后果只改变后续倾向，不直接硬编码“内疚就酗酒”之类固定剧情。不同人物可以以完全不同的方式消化同一种冲突。

## 19.3 价值观不是全部硬剪枝

少数绝对底线可以作为 Hard Boundary，但大部分价值观更适合作为 Strong
Aversion。否则守序角色永远不可能为了救孩子第一次偷药，人物也就失去了破例和戏剧张力。

# 20. 情绪、经验与成长

## 20.1 情绪是动态影响器

情绪适合影响注意力、风险感知、记忆提取和行为评分，但不直接等价于动作。不要写成“愤怒
\> 80 → Attack”。人格四轴也不应该被当作心理学定律，例如 I 或 T
不能自动等价为“压抑情绪”。

## 20.2 Experience Pattern

经历应该沉淀成可被反例修正的经验模式，而不是简单的“谨慎
+10”。建议关注强度、证据数量、泛化范围以及消退阻力。

Event  
→ Experience Pattern  
→ Evidence Accumulation  
→ Learned Bias / Strategy  
→ Future Counter-evidence can revise it

对于重大创伤，不建议只使用 isTrauma=true/false。更适合使用
extinctionResistance
之类连续强度：普通经验容易修正，高烈度经历很难被几次普通正向事件洗掉，但仍保留真正成长的可能。

# 21. Intent 与 Planning：心里想什么，不等于现在做什么

## 21.1 三层 Intent

Inner Stance  
“我恨他。”  
  
Committed Intent  
“我准备以后找机会报复。”  
  
Apparent Action  
“现在继续和他合作。”

只有需要作用于世界的 Apparent Action / Command 才提交 World
Runtime。内部立场可以长期存在，不应因为角色暂时微笑就被清零。

## 21.2 计划与局部重规划

第一版不急着实现完整 HTN。可以在现有 Goal 基础上增加
Plan、Step、Precondition、Abort Condition 与局部
Replan。当前步骤失败时换方案，而不是整个 Brain 重新初始化。

模型尤其适合在规则行为库无法覆盖复杂情境时，提出少量候选策略；随后仍由
Brain Controller 和世界规则过滤。

# 22. Character LOD：重要度 × 当前相关度

认知降级不应只看空间距离。更合理的是两个维度共同决定计算深度：人物重要度（Character
Importance）与当前事件/玩家相关度（Simulation Proximity / Relevance）。

Background Population  
→ 聚合模拟  
  
Minor Actor  
→ Needs + Utility + Goal + Simple Memory  
  
Major Character  
→ 完整 Character Mind  
  
Focus Character  
→ 当前剧情核心，高频推理 / 模型参与

一个远在另一座城市的重要人物仍保留人格、关系、长期目标和关键记忆，只是思考频率降低。一个就在玩家身边但完全不重要的路人，也不必立即升级为完整大脑。

## 22.1 休眠与重水化

重要人物长时间处于低频状态时，用粗粒度世界结算与关键事件差异保持连续性。重新进入高认知级别时，执行
Context Rehydration：根据 State Delta、Major Events
与旧人物状态生成当前背景认知。

重水化产生的是角色“现在如何理解这段时间”，不能反向编造世界事实。

# 23. 模型、规则与 Brain Controller 的权责边界

World Runtime  
决定：真实发生了什么  
  
Character Mind  
决定：我认为发生了什么，我想怎么办  
  
Director  
决定：世界给人物制造什么处境  
  
LLM / Laya / Local Model  
提供：理解、解释、策略候选、语言表达  
  
Brain Controller  
负责：调度、预算、权限、固化、回退

不能交给模型直接决定的内容包括资产变化、伤害结算、生死、位置、资源所有权、交易结果和世界事实。主观问题则可以采用混合式决策，不必强迫全部公式化。

## 23.1 复杂度预算决策表

| 问题类型                       | 优先实现方式          | 理由                           |
|--------------------------------|-----------------------|--------------------------------|
| 高频生存需求、资源、位置、死亡 | 规则 / Runtime        | 高影响、必须确定、必须重放     |
| Attention、可知性、权限过滤    | 规则优先              | 高频且直接影响性能与信息隔离   |
| 常见行为评分、Goal 连续性      | Utility / 规则        | 容易测试，适合回归             |
| 复杂语义理解、潜台词、策略灵感 | LLM / 小模型          | 规则化成本高，语义收益大       |
| 低频复杂心理解释               | LLM 按需生成          | 不值得为偶发情况建立重型模块   |
| 长期关键心理状态               | 结构化字段 + 模型辅助 | 需要连续性，但可让模型辅助解释 |
| 世界结果                       | 规则唯一裁决          | 防止模型越权                   |

# 24. 模型结果怎样进入确定性世界

模型并不需要每次重放都重新调用。关键模型输出一旦被 Brain Controller
接纳，并且会影响未来世界状态，就应作为版本化输入固化。后续恢复与回放使用已固化输入。

但不要把模型每一句“思考过程”都塞入世界日志。应区分 Brain
Thought、Committed Intent、Command 和 World
Fact，只保存真正会影响未来确定性的必要部分。

Brain Thought（临时）  
↓  
Committed Intent（必要时固化）  
↓  
Command（提交世界）  
↓  
World Fact（权威结果）

# 25. Mind Visualizer 与反事实调试

NPC Brain
如果没有可解释调试界面，后续涌现性问题会极难排查。开发者至少应该能看到：角色看到了什么、相信什么、当前动机、支持与反对因素、内部立场、当前意图和外在行为。

反事实调试建议分成两档：

- Fast Counterfactual：固定当前候选行为，只修改 trust、fear、need、role
  weight 等规则输入后快速重算，用于参数调试。

- Deep
  Counterfactual：允许重新调用策略模型，观察“角色连能想到的办法是否改变”，成本更高，用于少量复杂问题。

测试目标不应该是“高 T 必须选 A，高 F 必须选
B”，而应验证人格、经历、信念等因素确实按设计改变评分、倾向或候选集合，并且角色没有读取自己不该知道的信息。

# 26. V1 范围：先做一个真的能活的小脑袋

第一版不要追求完整认知科学。建议只保留能产生明显人物差异、又有工程收益的模块。

## V1 建议进入

- Perception / Actor-known 信息过滤。

- Attention Gate。

- Belief + Source + Confidence，保持 Fact 与 Interpretation 分离。

- Needs、Role、Values、Goal。

- 基础 Emotion。

- Behavior Profile / 行为库。

- Intent 三层中的 Inner Stance、Committed Intent、Apparent Action。

- Basic Planning / Replan。

- Memory + Experience Learning。

- Importance × Relevance 的 Cognitive LOD。

- LLM Strategy / Interpretation Provider，可按预算调用。

- Mind Visualizer 基础版。

## V2 / V3 再考虑

- 复杂谣言语义突变和大规模社会传播。

- 复杂创伤心理与救赎路径。

- 高级认知失调与身份长期崩解。

- 完整 HTN / 长链自主规划。

- 自动人生史深度生成。

- 复杂社会心理网络和群体意识形态演化。

# 27. 当前阶段的总原则

1\. 世界唯一真实，人物理解允许错误。

2\. Fact 与 Interpretation 永远分开。

3\. 模型不拥有世界写权限。

4\. 每条重要信息可以经过大脑，但不是每条信息都必须改变 Goal
或产生外显动作。

5\. 人格是倾向，不是命令表；价值观大多是强阻力，而不是绝对禁令。

6\. 主要人物拥有更完整的主观世界，次要人物沿用低成本 Needs / Utility /
Goal。

7\. Director 制造处境，不替人物决定答案。

8\. 复杂度必须有预算：高收益规律工程化，低收益复杂心理优先让 LLM
按需生成。

9\. 所有会影响世界连续性的关键外部模型结果都必须可追溯、可固化、可回放。

10\. 先做能运行、能测试、能解释的 V1，再逐步增加心理深度。

这份 v0.2
仍然是设计灵感保存点，不是冻结合同。它的作用是守住方向与边界：未来实现可以很简单，也可以逐步变复杂，但不能为了“聪明”牺牲世界权威、人物连续性和工程可控性。
